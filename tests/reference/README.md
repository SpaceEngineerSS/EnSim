# External validation data

`nesc_atmospheric_case_01_sim_06.csv` contains seven unmodified rows selected
at five-second intervals from NASA NESC's `Atmos_01_sim_06.csv`. The original
file is distributed in the official
[`Atmos_01_DroppedSphere.zip`](https://nescacademy.nasa.gov/src/flightsim/Datasets/Atmos_01_DroppedSphere.zip)
dataset for Atmospheric Check-Case 01.

- Downloaded: 2026-08-13
- Original ZIP SHA-256: `f04f139835db9e6c5be54d434c4dc6221ddc9ae6f34b6035d0798731bc0bf171`
- Original `Atmos_01_sim_06.csv` SHA-256: `c6183a9bd84a47915f52258d5892daa42c5228ba46a1ad64b744b788e096584a`
- Units and column meanings: NASA NESC 2015
  [Output Specifications](https://nescacademy.nasa.gov/flightsim/2015/output_specs)

The NESC files are a family of independently produced comparison solutions,
not a NASA declaration that any one simulator is exact. EnSim therefore calls
this a cross-comparison, not flight-test validation.

`nesc_atmospheric_case_02_sim_04.csv` contains the same seven-time subset from
NASA's `Atmos_02_sim_04.csv` for the dragless tumbling-brick case. Its source is
the official
[`Atmos_02_TumblingBrickNoDamping.zip`](https://nescacademy.nasa.gov/src/flightsim/Datasets/Atmos_02_TumblingBrickNoDamping.zip)
archive.
